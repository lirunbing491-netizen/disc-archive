导盘助手 · 光盘兼容测试版 使用说明

Windows 光盘兼容测试版　v0.4.1-beta.1
下载：https://github.com/lirunbing491-netizen/disc-archive/releases/download/v0.4.1-beta.1/DiscArchive-Optical-Windows.zip
需要单光驱稳定版时，可使用 v0.1.0（latest）：https://github.com/lirunbing491-netizen/disc-archive/releases/latest
将 DiscArchive-Optical-Windows.zip 完整解压，在 DiscArchive-Optical 文件夹内双击“导盘助手.exe”。请保留包内文件，包括 native 子目录里的只读 DLL，以及随包的许可证与对应版本的上游源码归档。等正在用的旧版本完成当前任务，正常退出后再运行此版。
需要 Windows 10/11、.NET Framework 4.7.2 或更高版本，无需管理员权限。目前没有 macOS 版。

这版更新了什么
这是在 Windows 上运行的导盘程序，可以读取普通数据盘，以及部分 Windows 无法显示目录的 Mac 格式光盘；无需安装 Mac 文件系统驱动。支持查重、跨日续导、项目别名和多个光驱，具体操作见下文。
本次修正了读盘收尾对完成状态的影响：文件已成功写入时，关闭光驱句柄或释放读取组件的异常单独保存在本盘登记，显示为“读盘收尾提示”。读取失败、写入失败或已知未覆盖内容仍会影响本张结果。若下一张遇设备占用，可正常退出后重开工具。

第一张怎么做
1. 准备光驱和空间充足的备份硬盘。在“导盘”页选择目标目录和光驱。
2. “本张项目”可以留空；明确知道项目时可以填写，下一张会恢复自动判断。
3. 先取出上一张盘。点“用摄像头拍盘面”，选择设备并打开预览，对准盘面，让标题尽量清楚，再点“拍下这张盘面”。也可以拖入、选择已有照片，或通过固定照片文件夹接收。
4. 放入与照片对应的盘，等待归类和复制。若光盘已在光驱内而工具未确认换盘，回导盘页核对照片并点“核对已放入的盘”。
5. 结束后查看结果。保持摄像头页也能看进度，上一张结束后可继续拍下一张。
没有摄像头可直接选择已有盘面图片；有摄像头时需允许 Windows 摄像头访问。

Windows 看不到目录的光盘
通常保持“读取方式”为“自动”。普通数据盘继续由 Windows 读取。Windows 挂载不出文件夹但光驱仍能读数据扇区时，程序会检查卷和分区，通过随包的 7-Zip 读取组件直接取文件。无需安装 Mac 文件系统驱动，也无需先把整张盘导成镜像。检测、续导、退出都不会写入光盘。
已放盘时，可以先点“检测盘格式…”。回到日常流程，拍盘面后选择当前光驱；如果盘已在驱内，点“核对已放入的盘…”。遇到混合盘可在登记前手选 Mac、UDF 或 ISO/Joliet 视图。每次登记处理所选视图；不同视图有可能呈现不同目录和文件名。多 Mac 数据分区会分别保留。
优先支持 HFS+、HFSX 和带 HFS+ 嵌入卷的旧式外壳。APM、GPT、MBR 是寻找数据卷的分区布局。传统 HFS 仅能辨认；APFS 提供实验性的可读卷提取，尚缺实际摄影盘验证，加密卷也可能无法读取。
已用真实 APM 分区 HFS+ DVD 验证列目录、文件抽样提取和整盘登记流程；抽样原档与 JPEG 已与独立扇区读取结果逐文件核对 SHA-256。这不代表整盘所有文件都经独立校验，也不保证其他光盘都能读取。HFSX 和多个 Mac 数据分区采用生成卷测试，旧式 HFS 外壳中的 HFS+ 定位仅经过布局测试。
ISO 9660/Joliet、UDF 1.02 已用带中文名和空目录的生成镜像验证。Windows 已能挂载的其他 UDF 版本仍可走系统路径；原始 UDF 入口只确认程序能解析的分区映射。DVD-Video 可按所选视图保留目录文件。音频 CD、VCD/XA 的特殊轨道、多会话的历史目录需要单独的轨道/会话处理。
普通文件保留数据叉。读取器可提供的 Mac 资源叉、扩展数据用单独的旁存文件保留，Windows 难以表示或重名的名称会安全改写；本盘记录中的“文件系统路径映射”可对照导出位置。符号链接和已检测出的原生硬链接占位不会当普通素材跟随或计为成功。此版不重放日志，不保证还原所有 Mac 权限、属性或压缩存储结构；发现卷状态异常时会尽量保留可读文件，并记录未确认范围。

忘了这张是否导过
照常拍照、放盘。工具在当前备份根目录查旧登记，比较相对目录、文件名、大小和少量内容抽样。同项目的 1-1、1-2 可以共用卷标。只有出现候选时才请你对照盘面照片、原盘号和分盘编号。确认同一张，工具核对并补缺。确认是另一张，则独立存档。拿不准可点“暂不导入”。
新版本在首次拷贝中为完整文件记录 SHA-256。以后强匹配且你确认是原盘时，会读回硬盘上的已有文件核对摘要；正确的计入“沿用”。如果所有文件都正确，会显示“已导过，核对完成”，本次新拷 0 个。抽样相同只能说明可能是同盘。首次读取、识别未完整或两份盘有部分相同素材，都有可能无法给出唯一候选。

今天暂停、明天换光驱
点“暂停本张”，等结果出来后可退出。第二天接回同一份备份盘或共享目录，选现在的光驱，在登记册选原记录点“核对 / 续导原盘”，也可在导盘页点“按旧盘号续导…”。原光驱可拔走；同一备份位置换了访问路径时，可用旧盘号从该位置的登记和原照恢复。重新拍照插盘时也会查找候选。这次的插盘记录和原盘号会关联，原有照片与日志保留。
恢复按文件进行。中断时尚未写完整的那个文件从头读；缺失的文件补拷，已验证的沿用。发现同大小但内容已变的旧副本会保留，正确数据另存。正常新盘会在拷贝的那一遍生成摘要；旧版已有成功清单却没有文件摘要，第一次续导通常需要额外读取原盘和硬盘进行比对。坏盘上读不出的文件不会据此算作已核对。
查重范围是当前选中的备份根目录。其他离线硬盘当下查不到。旧记录的自动发现有界且按批补建索引，知道盘号时可直接使用。若旧清单遗失或互相矛盾，可能无法安全续用原路线，程序会说明情况。

几个卷标像是同一个项目
同一天、完整项目文字等价且只有一个已有候选时，会沿用已有目录，例如全半角、空格或日期分隔方式不同。错字、简称和相似名称只供选择。你可以确认归入已有项目，或保留本次名称另建。拍照前也可点“选已有项目…”直接指定。明确确认的名称对应关系记在这份归档位置；混装、未知项目等含糊名称只作本盘决定。以前已经拷好的目录和素材保持原位。

同时用多个光驱
在机身上标好盘符会更好操作。先在窗口顶部选第一台，拍盘面并把盘放进这台。切到第二台再拍、再放；第一台继续拷。摄像头可保持预览。窗口顶部能查看所有任务，点盘符可看对应照片和详细进度。停止本张只影响选中的光驱，完成提示也会显示盘符。固定照片文件夹只给启用自动接收时选中的一台光驱分配照片。

几台电脑一起导盘
各电脑可使用各自硬盘。如果希望素材归入同一项目库，请在各电脑打开本测试版，把“新盘存到”设为同一个支持文件共享锁的 SMB 根目录，可直接粘贴共享路径。不同盘同时有同名素材时，各自的文件均会保留。请保留根目录的 .discarchive-coordination-v1 文件夹，旧版适合写入独立目标。登记册的“导出本机表”只包含本机记录，“导出归档盘总表”会读取指定目标上各工位已发布的记录，适用于共享盘或移动硬盘。不同独立硬盘可分别导出。

怎么命名、怎么放
默认“仅卷标与元数据”，无需账号、模型或联网。拍照后保存原图，不自动识字；放盘后结合卷标、原目录和必要时抽取的素材元数据，确定归档路径后开始复制。
项目目录名包含六位年月日。优先采用明确文字和可用的拍摄元数据，再参考文件名或源文件修改日期；修改日期只能作为归档线索，不能等同拍摄日期。没有可信日期时使用导入日，并注明拍摄日未知。日期有分歧时可在“命名依据”查看取值原因。
同一盘的不同格式和机位不会因此拆成多个项目；只有明确的不同项目证据才分组，其余内容按线索或“混装待归属”保留。原目录结构随归档保留。同名文件夹或文件冲突时另存到“来源-盘号”等目录，避免覆盖。
原始盘面照片保存在对应项目的“盘面照片”中。素材内部拍摄信息随原文件保留；目标文件和目录的创建、修改时间由 Windows 记录，应与项目日期线索分开理解。

遇到坏盘
某个文件读取失败时，程序记录失败路径并继续其他文件。只有读到源文件原长度并刷入目标硬盘后，才作为完整文件发布。中断残片留在本盘记录的“未完成残片”中，可与失败清单对应。
遇到目标硬盘掉线、空间不足或光盘被换走，程序停止本轮并保留已拷出的内容。坏区可能触发光驱反复重试，让单次读取停留较久。
结果包括“已拷出”“部分拷出”“待复查”；失败条目也可能是无法列出内容的整个目录。结束时会弹出本张项目、盘号、完整文件数和失败条目数，主窗口最小化也会提示。
默认不试播、不做目标完整回读哈希。“已拷出”只描述本次可见文件的读取与写入结果，不保证素材可播放，也不是专业坏扇区恢复。无法挽救光驱读不到的坏区或已损坏内容；音频 CD、VCD/SVCD 的不可见轨道不在可见文件归档能力内。需要确认播放或内容完整性时，请另行检查。

可选识图
普通同事可以保持默认设置，不用配置模型。
“本机文字识别”使用 Windows 离线 OCR，无需账户或网络，依赖可用的系统识别语言。清晰印刷标题更适合识别；手写盘面可能识别不准，只能作为线索。
“使用自配看图模型”可填写支持图片的 Chat Completions 兼容地址、服务商提供的模型 ID 和密钥。服务地址可以是基础地址或完整 chat/completions 地址。保存后生效。
启用模型后，拍照、选图、拖入、自动接收新图和重读已有光盘时，都会把处理后的盘面图发送到所填服务，可能计费。默认按检测到的圆盘裁切并遮住盘外和中心孔，定位失败时会改用卷标等线索。若主动勾选“允许发送整张照片”，定位失败时可能发送重编码整图，画面可能包含人物和背景。
“测试看图接口”会用合成盘面发起一次真实请求，可能收费。测试通过只代表这项简单图片测试通过，不能保证实际手写盘名的识别效果。接口超时或拒绝时仍可继续归档；原因可在登记册的“归类依据”中查看。
密钥使用当前 Windows 账户保护。不要公开密钥、个人设置或私人照片。

查记录与备份
在“登记册”按标题、盘号、项目或状态查找。“打开归档”进入实际项目目录；一张盘涉及多个项目时可以选择目标。“本盘记录”查看路径清单、失败清单、进度和残片。后改标题或项目标签不会移动已有素材的磁盘路径。
目标硬盘的 DiscArchive 目录按盘号保存登记、续导账本和读取记录。请把该目录和根目录的 .discarchive-* 记录与项目素材一同保留。本版的本机总册位于 %LOCALAPPDATA%\DiscArchive\工作站\Mac光盘兼容试用版。导出的总表同时列有“原盘号”和本次登记号。统计实盘数时按原盘号去重。
首次启动会从可用的旧登记册复制记录，此后新旧版本机总册分别保存，不要同时运行。备份前关闭程序，复制整个 %LOCALAPPDATA%\DiscArchive\工作站 目录（包括旧照片），并单独备份目标硬盘上的素材和记录。仅复制程序文件不等于备份归档资料。
