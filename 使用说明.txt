导盘助手 · DiscArchive 使用说明

下载
https://github.com/lirunbing491-netizen/disc-archive/releases/latest
当前为公开试用版。下载 DiscArchive-Windows.zip 后解压整个压缩包。在 DiscArchive 文件夹内双击“导盘助手.exe”，保留同目录的其他文件（配置、识字脚本、本说明和许可证）。
需要 Windows 10/11、.NET Framework 4.7.2 或更高版本，无需管理员权限。目前没有 macOS 版。

第一张怎么做
1. 准备光驱和空间充足的备份硬盘。在“导盘”页选择目标目录和光驱。
2. “本张项目”可以留空；明确知道项目时可以填写，下一张会恢复自动判断。
3. 先取出上一张盘。点“用摄像头拍盘面”，选择设备并打开预览，对准盘面，让标题尽量清楚，再点“拍下这张盘面”。也可以拖入、选择已有照片，或通过固定照片文件夹接收。
4. 放入与照片对应的盘，等待归类和复制。若光盘已在光驱内而工具未确认换盘，回导盘页核对照片并点“核对已放入的盘”。
5. 结束后查看结果。保持摄像头页也能看进度，上一张结束后可继续拍下一张。
没有摄像头可直接选择已有盘面图片；有摄像头时需允许 Windows 摄像头访问。

怎么命名、怎么放
默认“仅卷标与元数据”，无需账号、模型或联网。拍照后保存原图，不自动识字；放盘后结合卷标、原目录和必要时抽取的素材元数据，确定归档路径后开始复制。
项目目录名包含六位年月日。优先采用明确文字和可用的拍摄元数据，再参考文件名或源文件修改日期；修改日期只能作为归档线索，不能等同拍摄日期。没有可信日期时使用导入日，并注明拍摄日未知。日期有分歧时可在“命名依据”查看取值原因。
同一盘的不同格式和机位不会因此拆成多个项目；只有明确的不同项目证据才分组，其余内容按线索或“混装待归属”保留。原目录结构随归档保留。同名文件夹或文件冲突时另存到“来源-盘号”等目录，避免覆盖。
原始盘面照片保存在对应项目的“盘面照片”中。素材内部拍摄信息随原文件保留；目标文件和目录的创建、修改时间由 Windows 记录，应与项目日期线索分开理解。

遇到坏盘
某个文件读取失败时，程序记录失败路径并继续其他文件。只有读到源文件原长度并刷入目标硬盘后，才作为完整文件发布。中断残片留在本盘记录的“未完成残片”中，可与失败清单对应。
遇到目标硬盘掉线、空间不足或光盘被换走，程序停止本轮并保留已拷出的内容。坏区可能触发光驱反复重试，让单次读取停留较久。
结果包括“已拷出”“部分拷出”“待复查”；失败条目也可能是无法列出内容的整个目录。结束时会弹出本张项目、盘号、完整文件数和失败条目数，主窗口最小化也会提示。
默认不试播、不做目标完整回读哈希。“已拷出”只描述本次可见文件的读取与写入结果，不保证素材可播放，也不是专业坏扇区恢复。无法挽救光驱读不到的坏区或已损坏内容；音频 CD、VCD/SVCD 的不可见轨道不在可见文件归档能力内。需要确认播放或内容完整性时，请另行检查。

可选识图
普通同事可以保持默认设置，不用配置模型。
“本机文字识别”使用 Windows 离线 OCR，无需账户或网络，依赖可用的系统识别语言。清晰印刷标题更适合识别；手写盘面可能识别不准，只能作为线索。
“使用自配看图模型”可填写支持图片的 Chat Completions 兼容地址、服务商提供的模型 ID 和密钥。服务地址可以是基础地址或完整 chat/completions 地址。保存后生效。
启用模型后，拍照、选图、拖入、自动接收新图和重读已有光盘时，都会把处理后的盘面图发送到所填服务，可能计费。默认按检测到的圆盘裁切并遮住盘外和中心孔，定位失败时会改用卷标等线索。若主动勾选“允许发送整张照片”，定位失败时可能发送重编码整图，画面可能包含人物和背景。
“测试看图接口”会用合成盘面发起一次真实请求，可能收费。测试通过只代表这项简单图片测试通过，不能保证实际手写盘名的识别效果。接口超时或拒绝时仍可继续归档；原因可在登记册的“归类依据”中查看。
密钥使用当前 Windows 账户保护。不要公开密钥、个人设置或私人照片。

查记录与备份
在“登记册”按标题、盘号、项目或状态查找。“打开归档”进入实际项目目录；一张盘涉及多个项目时可以选择目标。“本盘记录”查看路径清单、失败清单、进度和残片。后改标题或项目标签不会移动已有素材的磁盘路径。
目标硬盘的 DiscArchive 目录按盘号保存登记和读取记录。本机总册位于 %LOCALAPPDATA%\DiscArchive\工作站\抢救版。
首次启动会从可用的旧登记册复制记录，此后新旧版本机总册分别保存，不要同时运行。备份前关闭程序，复制整个 %LOCALAPPDATA%\DiscArchive\工作站 目录（包括旧照片），并单独备份目标硬盘上的素材和记录。仅复制程序文件不等于备份归档资料。
