# 导盘助手 · DiscArchive

把旧光盘中仍可读取的文件，连同盘面照片和读取记录，整理到备份硬盘。适合逐张处理历史素材光盘，按项目归档并保留原目录结构。当前为公开试用版。

默认不需要账户、模型或网络。准备一台 Windows 电脑、可读取光盘的光驱和空间充足的目标硬盘；盘面照片可以用摄像头拍，也可以选择已有图片。

## 下载与开始

[下载 Windows 便携版](https://github.com/lirunbing491-netizen/disc-archive/releases/latest/download/DiscArchive-Windows.zip) · [查看发行说明](https://github.com/lirunbing491-netizen/disc-archive/releases/latest)

解压整个压缩包，打开其中的 `DiscArchive` 文件夹，双击 `导盘助手.exe`。请把同文件夹的配置文件、识字脚本和使用说明一起保留。

1. 在“导盘”页选择目标目录和光驱，“本张项目”可以留空，由工具按可用线索判断。
2. 取出上一张盘，用“用摄像头拍盘面”拍照，或选择、拖入已有盘面照片。
3. 放入对应光盘，等待归类与复制。未能确认换盘时，核对照片后点“核对已放入的盘”。
4. 查看本张结果和登记册，再换下一张。遇到“部分拷出”或“待复查”，查看失败清单。

完整操作见[使用说明](使用说明.txt)。

## 归档与读取边界

- 默认“仅卷标与元数据”：盘面照片用于留档，不识字、不发往网络。项目名与日期结合卷标、目录和必要时抽取的素材元数据判断；无可靠项目日期时，使用导入日并注明拍摄日未知。
- 项目文件夹中的日期是归档命名线索。原文件内的拍摄信息随内容保留；目标文件和目录的创建、修改时间由 Windows 记录，不应当作原拍摄日期。
- 同一项目下保留原有文件结构。同名内容发生冲突时另存到“来源-盘号”等目录，避免覆盖已有内容。不同格式或机位本身不会使同盘被拆成多个项目。
- 某个文件读坏后会登记失败路径并继续其他文件。完整读到源长度并写入、刷入目标硬盘的文件才发布到归档位置；中断残片单独保留。“已拷出”表示本次可见文件的读取与写入结果。
- 默认不试播、不做目标完整回读哈希。不能据此保证素材可播放、内容完整无损，也不能恢复光驱无法读取的坏扇区、不可见轨道或已损坏内容。音频 CD、VCD/SVCD 的不可见轨道不在可见文件归档能力内。
- 目标硬盘掉线、空间不足或光盘被换走会停止本轮，保留已拷出的内容。不要在任务完成前拔出目标硬盘。

## 可选识图与隐私

普通使用无需配置“识图设置”。需要时可选 Windows 本机文字识别，无需账号或联网；手写盘面可能识别不准，结果只作线索。

也可自行配置支持图片输入的 Chat Completions 兼容服务。启用后，每次登记或重读光盘时，工具会将处理过的盘面照片发送给填写的服务商，费用按服务商规则计算。拍照、选图、拖入和自动接收文件夹中的新图都适用。请求中的图像取自盘面照片。默认按检测到的圆盘裁切并遮盖盘外与中心孔，定位失败时会改用卷标等线索。只有自己勾选允许发送整图后，定位失败才会发重编码的整张照片，其中可能包含人物和背景。“测试看图接口”发送一张程序生成的字符图，也可能计费。

密钥使用当前 Windows 账户保护。请勿把实际密钥、个人设置、盘面照片或归档资料提交到代码仓库。

## 系统要求与构建

面向 Windows 10/11、.NET Framework 4.7.2 或更高版本，无需管理员权限。摄像头功能需要可用设备和 Windows 摄像头访问权限；没有摄像头可选择已有图片。本机 OCR 依赖系统支持及可用的识别语言。当前没有 macOS 版本。

在 Windows PowerShell 5.1 中进入源码目录，运行：

```powershell
.\build.ps1
.\test.ps1
```

构建使用 Windows 自带的 .NET Framework C# 编译器和系统程序集，不需要安装额外收费依赖。保留应用清单及配置文件，供 Windows 兼容性设置和运行时使用；OCR 脚本与程序一起分发。

便携程序输出到 `dist/DiscArchive/`；发行压缩包为 `dist/DiscArchive-Windows.zip`。压缩包仅包含 `DiscArchive/` 根文件夹下的五个文件：`导盘助手.exe`、`导盘助手.exe.config`、`LabelOcr.ps1`、`使用说明.txt`、`LICENSE`。构建不会自动上传或发布。

测试脚本的自动检查不能代替真实光驱、坏盘和摄像头上的使用验收。

## 数据与备份

目标硬盘的 `DiscArchive` 目录保存按盘号组织的登记与读取记录。本机登记册位于 `%LOCALAPPDATA%\DiscArchive\工作站\抢救版`。从旧版首次启动时，会复制可用的旧登记记录，新旧版之后各自保存；不要同时运行。备份前关闭程序，连同旧照片一起复制整个 `%LOCALAPPDATA%\DiscArchive\工作站` 目录，并单独备份目标硬盘上的素材和记录。
