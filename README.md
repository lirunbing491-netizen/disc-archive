# 导盘助手 · 光盘兼容测试版

把旧光盘中仍可读取的文件，连同盘面照片和读取记录，整理到备份硬盘。适合逐张处理历史素材光盘，按项目归档并保留原目录结构。当前为公开试用版。

Windows 与 macOS 都可以离线使用。接好光驱和备份硬盘，用摄像头拍盘面或选择已有照片即可开始。

## 下载与开始

**[阅读中文操作手册](操作手册.md)** · [纯文本手册](使用说明.txt) · **[v0.4.4-beta.1 官方下载页](https://github.com/lirunbing491-netizen/disc-archive/releases/tag/v0.4.4-beta.1)**

| 电脑 | 下载与打开 |
| --- | --- |
| Windows 10 / 11 | [下载 Windows ZIP](https://github.com/lirunbing491-netizen/disc-archive/releases/download/v0.4.4-beta.1/DiscArchive-Windows-0.4.4-beta.1.zip)，完整解压后打开“导盘助手.exe”。 |
| Intel 或 Apple 芯片 Mac，目标 macOS 13 起 | [下载 Mac 通用 ZIP](https://github.com/lirunbing491-netizen/disc-archive/releases/download/v0.4.4-beta.1/DiscArchive-macOS-Universal.zip)，解压后打开 DiscArchive.app。首次打开的信息见[Mac 说明](macos/README.md)。 |

从旧版升级时，请等正在导的盘结束，关闭旧版，再打开新程序。两份 ZIP 内均附有同一份《使用说明》。此前发布的 [Windows 单光驱稳定版](https://github.com/lirunbing491-netizen/disc-archive/releases/tag/v0.1.0) 仍可下载。

1. 在“导盘”页选择目标目录和光驱，“本张项目”可以留空，由工具按可用线索判断。
2. 取出上一张盘，用“用摄像头拍盘面”拍照，或选择、拖入已有盘面照片。
3. 放入对应光盘，等待归类与复制。未能确认换盘时，核对照片后点“核对已放入的盘”。
4. 正常完成并写好回执后，程序会请求本次光驱弹盘。部分拷出时可留盘重试。遇到“待复查”，先查看本张结果和失败清单。

完整操作见[使用说明](使用说明.txt)。

## 这版更新了什么

- 摄像头预览就绪后可用回车或空格拍照。多个光驱各自绑定照片、独立读取。
- 登记册显示本机已导盘数，支持补录、修改标签、从本机移除与恢复。拍摄原档和硬盘回执保持原位。
- 在完成提示或导盘页可发起重试，复用原照片和回执。设备拒绝弹盘时会显示结果。
- 支持查重、跨日续导、项目别名和多个光驱；原目录与已有素材保持原位，具体操作见下文。
- 修正读盘收尾对完成状态的影响：文件已成功写入时，释放读取组件或关闭光驱句柄遇到的异常单独记录为“读盘收尾提示”。读取失败、写入失败和已知未覆盖内容仍会影响本张结果。若下一张遇设备占用，可正常退出后重开工具。

## 光盘能读扇区，但 Windows 没有显示目录

先试“自动”。工具优先使用 Windows 可读的目录；挂载失败时，以只读方式打开光驱、识别分区，再按文件提取。可在登记前点“检测盘格式…”。整个流程使用用户态读取组件，无需为 Mac 光盘安装文件系统驱动。

| 格式 | 本版覆盖与证据 |
| --- | --- |
| HFS+ | 已用真实 APM 分区 DVD 验证列目录、文件抽样提取和整盘登记流程；抽样原档与 JPEG 已与独立扇区读取结果逐文件核对 SHA-256。抽样核对不代表整盘所有文件均经独立校验。 |
| HFSX、嵌入式 HFS+、多个 Mac 数据分区 | HFSX 读取和多个分区的隔离提取用生成卷测试，早期 HFS 外壳内的 HFS+ 定位通过布局测试。 |
| ISO 9660、Joliet、UDF | 正常挂载走系统路径；原始视图已用 ISO/Joliet/UDF 1.02 混合镜像交叉验证长中文名、空目录与文件字节。原始 UDF 解析入口目前确认单一 type-1 分区映射。 |
| 混合盘 | 同一张盘可显示 Mac、ISO 和 UDF 目录。可显式选读取视图，每次记录本次所见。 |
| APFS | 实验性的可读卷入口，仅布局探测做过合成验证。加密卷、快照和不同实际 APFS 版本的提取尚未验收。 |
| 传统 HFS、音频或特殊轨道、多会话 | 可报告已识别的格式或轨道线索。纯传统 HFS、CD 音轨、VCD/XA 特殊扇区和历史会话不在本版提取范围。 |

Mac 资源叉等可见辅助流以旁存文件保存，路径对应关系记录在本盘日志。已识别的硬链接占位和无法读取的范围会留下明确的结果。HFS+ 日志不重放；选择视图的文件级提取并非整盘镜像。部分压缩文件按需使用单文件临时空间。

格式依据见 [Apple TN1150](https://developer.apple.com/library/archive/technotes/tn/tn1150.html)、[7-Zip 官方支持列表](https://www.7-zip.org/)及[随版本固定的格式说明](vendor/7zip/FORMAT-NOTES.md)。

## 查重、续导与项目名称

- 插盘时用相对目录、长度和限量内容抽样查找当前备份位置中的候选盘。出现候选时由操作者确认，单凭同一卷标不会跳过拷贝。
- 点“暂停本张”，之后可在另一台光驱或工位用原盘号继续。完整文件有持久 SHA-256 回执。续导核对目标，沿用正确文件，补齐缺失项，并保护内容已变的旧副本。中断文件从头读取。旧版无摘要的清单需要额外比对原盘与硬盘。
- 格式等价的项目名可沿用已有位置。近似名称需明确选择，已确认的别名仅对当前备份根生效。历史目录和素材不会被自动搬动。

## 多光驱与多台电脑

**同一台电脑**打开一个窗口即可。选择顶部光驱、拍照、放盘，再选另一台拍下一张。每台分别等待、读取和显示结果，停止时只影响所选光驱。外部相机拍好的图片可手选或拖入。

**多台电脑**各自连接备份硬盘即可独立工作。Mac 使用本机或直连的可写文件夹。Windows 工位也支持将“新盘存到”设为同一 SMB 共享根目录，各工位需具备写入权限且共享存储需支持文件锁。

“登记册”可导出本机表，也可用“导出归档盘总表”汇总一个目标目录下各工位已登记的光盘。归档盘总表按当前访问路径列出素材位置。归档根目录内的 `.discarchive-coordination-v1` 用来保留输出归属，与 `DiscArchive` 登记目录一起保留。

## 归档与读取边界

- 默认“仅卷标与元数据”：盘面照片用于留档，不识字、不发往网络。项目名与日期结合卷标、目录和必要时抽取的素材元数据判断；无可靠项目日期时，使用导入日并注明拍摄日未知。
- 项目文件夹中的日期是归档命名线索。原文件内的拍摄信息随内容保留；目标文件和目录的创建、修改时间由 Windows 记录，不应当作原拍摄日期。
- 同一项目下保留原有文件结构。同名内容发生冲突时另存到“来源-盘号”等目录，避免覆盖已有内容。不同格式或机位本身不会使同盘被拆成多个项目。
- 某个文件读坏后会登记失败路径并继续其他文件。完整读到源长度并写入、刷入目标硬盘的文件才发布到归档位置；中断残片单独保留。“已拷出”表示本次可见文件的读取与写入结果。
- 默认不试播、不做目标完整回读哈希。不能据此保证素材可播放、内容完整无损，也不能恢复光驱无法读取的坏扇区、不可见轨道或已损坏内容。音频 CD、VCD/SVCD 的不可见轨道不在可见文件归档能力内。
- 目标硬盘掉线、空间不足或光盘被换走会停止本轮，保留已拷出的内容。不要在任务完成前拔出目标硬盘。

## 可选识图与隐私

普通使用无需配置“识图设置”。需要时可选 Windows 本机文字识别，无需账号或联网；手写盘面可能识别不准，结果只作线索。

也可自行配置支持图片输入的 Chat Completions 兼容服务。选择模型模式并保存后，登记或重读时会按服务商费率调用。默认发送遮掉圆盘外背景和中心孔的盘面图，定位失败则使用卷标等线索。如果主动允许整图，定位失败时会发送重编码后的整张照片，可能含人物和背景。接口自测发送程序生成的字符图。

Windows 使用当前账户加密保存配置的服务密钥，Mac 使用系统钥匙串。公开包默认离线，需要外部模型时由使用者填写自己的服务设置。

## 系统要求与构建

Windows 10/11 需要 .NET Framework 4.7.2 或更高版本，摄像头需要 Windows 授权。本机 OCR 使用系统可用的识别语言。Mac 打包和运行说明见 [macos/README.md](macos/README.md)。

在 Windows PowerShell 5.1 中进入源码目录，运行：

```powershell
.\build.ps1
.\test.ps1
```

构建使用 Windows 自带的 .NET Framework C# 编译器和系统程序集，不需要安装额外收费依赖。保留应用清单及配置文件，供 Windows 兼容性设置和运行时使用；OCR 脚本与程序一起分发。

Windows 便携程序及同名 ZIP 生成在 `dist/DiscArchive-Windows-0.4.4-beta.1` 和 `dist/DiscArchive-Windows-0.4.4-beta.1.zip`。请保留包内运行组件和许可证。

测试脚本的自动检查不能代替真实光驱、坏盘和摄像头上的使用验收。

## 数据与备份

目标硬盘的 `DiscArchive` 目录保存按盘号组织的登记与续导回执，根目录的 `.discarchive-*` 保存协作和识别信息。本版登记册位于 `%LOCALAPPDATA%\DiscArchive\工作站\Mac光盘兼容试用版`，首次启动会复制已有登记，之后与之前版本各自保存。备份前关闭程序，连同旧照片一起复制整个 `%LOCALAPPDATA%\DiscArchive\工作站` 目录，并单独备份目标上的素材和记录。
