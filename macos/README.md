# Mac 版导盘助手

将盘内仍能读取的素材原样归到所选硬盘，每张盘的盘面照片、登记和读取结果与素材一起保存。此分支以 macOS 13 为最低目标，Intel 和 Apple 芯片共用一份应用。运行时已随包提供。

## 获取测试包

打开仓库 Actions 中本分支绿色的 **Mac native build and tests** 记录，下载产物 **DiscArchive-macOS-Universal**。解开外层下载包，再解开其中的 `DiscArchive-macOS-Universal.zip`，双击 `DiscArchive.app`。同级 `SHA256.txt` 是内层 ZIP 的摘要。测试包使用本地签名，尚未经过 Apple 开发者身份签名和公证。

## 导第一张盘

1. 接好光驱和备份盘，在导盘页选实际使用的光驱和备份文件夹。多台光驱可分别操作，同一台电脑上也可切换备份盘。
2. 在摄像头页选择内置或外接摄像头，选定光驱后拍盘面。也可以导入已有照片。首次拍摄时，按系统提示允许摄像头访问。
3. 把盘放进刚选的光驱。等待识图和系统就绪期间可以处理另一台光驱。预先插过盘或无法确认换盘时，按界面提示核对。系统如询问可移动卷访问，允许访问所选卷。
4. 登记册会记录拷出情况。遇到坏文件会尽量继续读其余文件。中途离开可停止所选任务，之后重新接上原备份盘、放入同张盘，通过原记录续导。用项目选择或别名统一目录名。

盘面可在本机识字，也可使用卷标和素材日期。调用外部识图服务需自行配置并选择相应模式，服务密钥存入系统钥匙串。一般导盘可离线使用。识图设置、项目归类和复制规则见工作台及仓库首页。

## 光盘与文件

自动读取优先采用系统已挂载的光盘目录。系统没有挂载时，应用可尝试以只读方式读取所选光驱，按已识别的分区处理 HFS+、HFSX、ISO、Joliet 和受支持的 UDF。APFS 入口为实验性。某些设备可能限制原始扇区访问，相关错误会写入当前任务。音轨、旧会话和纯传统 HFS 的提取不在本版范围。

数据文件保留原有层级。Mac 资源叉、Finder 信息等可见辅助内容以旁存文件和路径记录保存。目标文件的修改时间由备份硬盘正常记录，素材内部时间信息随原始字节复制。选择跨平台使用的备份盘时，应确保两端都能写入该卷。

## 从源码构建

在对应架构的 macOS 上准备 Xcode 命令行工具和 .NET 8 SDK。在仓库根目录运行以下一条命令，使用新的输出目录。

```sh
bash macos/build.sh x64 "$PWD/dist/intel"
bash macos/build.sh arm64 "$PWD/dist/apple"
```

将两个构建目录带到一台 Mac 后，运行 `bash macos/combine.sh dist/intel/DiscArchive.app dist/apple/DiscArchive.app dist/universal`。脚本验证主程序、设备读取组件及各平台随包运行时的芯片类型，然后生成压缩包。

构建使用合成镜像和临时目录测试读取、归类、续导和权限。实体光驱的换盘检测、摄像头画面、真实坏盘和 macOS 13 上的实际体验需要在相应机器上验证。第三方组件见 [许可清单](THIRD-PARTY.txt)。
